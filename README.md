# ProcessamentoDeCadeias-AEDII-2026.2
Projeto em grupo sobre Processametno de Cadeias.AEDII-2026.2.

# Descrição do projeto:
Considere uma aplicação computacional
de um estudo de caso real ou realístico
escolhido pelo grupo. Essa aplicação faz
uso de algoritmo de processamento de
cadeias de Força Bruta e de algoritmo de
processamento de cadeias Knuth, Morris
e Pratt (KMP). Implemente essa
aplicação, analise comparativamente (de
forma teórica e prática com experimentos
computacionais) e conclua sobre qual das
duas alternativas de algoritmos resultaria
mais efetiva para a aplicação em termos
de complexidade de tempo, complexidade
de espaço, tempo prático de execução
das operações e facilidade de
implementação.
