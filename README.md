# Processamento De Cadeias - AEDII - 2026.2

Projeto em grupo sobre Processamento de Cadeias desenvolvido durante o segundo quadrimestre de 2026 na disciplina de Algoritmos e Estruturas de Dados II na UFABC.

## Descrição do projeto

Desenvolvimento de uma aplicação para a análise de **casamento de cadeias**. A aplicação utiliza os algoritmos de **Força Bruta** e **Knuth, Morris e Prath (KMP)**. Em conjunto, é feita a análise comparativa, teorica e empírica, entre ambos os algoritmos. A análise leva em conta os seguintes aspectos:
- Complexidade de tempo
- Complexidade de espaço
- Tempo prático de execução das operações
- Facilidade de implementação
